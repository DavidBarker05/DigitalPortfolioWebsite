About the Game

You are a contractor helping fix the infrastructure in an informal settlement in South Africa. To do so, you have moved into the informal settlement and must help your neighbours with the infrastructure in their houses. You will be fixing electrical wires, finding broken pipes and fixing them and even disconnect people who are illegally using another person's power. By helping people you will earn money which can be used to buy upgrades that make doing jobs easier.

About the Project

For this project we were required to make a game that focused on an issue affecting South Africa. So our group decided to create a game that focused on the issue of lack of infrastructure in informal settlements.

Requirements:

  • The game must have a tutorial
  • The game must contain one level outside of the tutorial
  • The game must have an ending
  • The game must be published to itch.io
